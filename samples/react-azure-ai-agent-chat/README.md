# Azure AI Agent Chat

An SPFx 1.23.2 web part that connects to Azure AI Agent Service using the `@azure/ai-projects` SDK. Chat with an AI agent directly from SharePoint.

<img src="https://m365-visitor-stats.azurewebsites.net/sp-dev-fx-webparts/samples/react-azure-ai-agent-chat" />

## Prerequisites

- Node.js >= 22.14.0
- SharePoint Framework 1.23.2
- An Azure AI Project connection string

## This sample illustrates...

- Connecting a SharePoint Framework web part to Azure AI Agent Service.
- Using the `@azure/ai-projects` SDK from an SPFx solution.
- Building an in-page chat experience for interacting with an AI agent from SharePoint.
